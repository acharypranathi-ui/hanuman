# Hanuman Estates — Modern Real Estate Landing Page & AI Chatbot

A luxury real estate landing page and AI property concierge web application designed for **Hanuman Estates**, inspired by boutique real estate presentation benchmarks.

---

## 🌟 Key Features

1. **Header & Sticky Navigation**
   - Elegant logo with house/hotel luxury badge.
   - Smooth navigation links (*Home, About Us, Properties, Services, Gallery, Testimonials, Contact*).
   - Prominent **“Enquire Now”** CTA button.
   - Fully responsive **mobile hamburger menu** with fluid animations.

2. **Hero Section & Search Interface**
   - High-resolution luxury property imagery with gold accent gradients.
   - Main heading: *“Find Your Dream Property with Hanuman Estates”*.
   - Interactive search bar with filters for:
     - Preferred Location (Bangalore, Mumbai, Gurgaon, Hyderabad)
     - Property Type (Villas, Penthouses, Apartments, Commercial, Plots)
     - Budget Range
     - Transaction Type (*Buy* vs. *Rent*)

3. **About Us Section**
   - Professional company philosophy, 15+ years experience badge, and clear-title guarantees.
   - Verified credentials & customer-service highlights.

4. **Our Services**
   - 6 clean interactive cards with icons:
     - Residential Property Sales
     - Property Rentals
     - Commercial Properties
     - Land & Plot Enquiries
     - Property Consultation
     - Property Listing Assistance
   - Direct enquiry integration on every card.

5. **Featured Properties with Dynamic Filtering**
   - Responsive cards with high-definition imagery, price tags, location, square footage, bed/bath counters.
   - **Interactive Modal:** “View Details” opens a comprehensive property overview with schedule visit options.
   - Quick **“Enquire”** button directly prefills the enquiry form for that exact listing.
   - Working filter tabs (*All, Villa, Penthouse, Apartment, Commercial, Plot, For Sale, For Rent*).

6. **Property Gallery & Lightbox**
   - Responsive mosaic masonry grid.
   - Hover effects with title & category overlay.
   - Fullscreen **Click-to-Enlarge Lightbox** with high-definition views.

7. **Why Choose Hanuman Estates**
   - Customer-centric value propositions: Transparent Pricing, Legal Verification, Personalized Tours, Responsive Support.

8. **Client Testimonials**
   - Authentic review cards featuring star ratings, client names, roles, and avatar images.

9. **Enquiry Form & Contact Desk**
   - Interactive form capturing: Full Name, Phone, Email, Property Type, Budget, Location, and Message.
   - Complete front-end validation (email format, telephone digits, required fields).
   - Instant visual error indicators and animated success message.
   - Direct links for **WhatsApp** and **Google Maps**.

10. **Interactive AI Chatbot Concierge**
    - Floating gold-accented bot widget available across all pages.
    - Tailored conversational logic for real estate queries (pricing, villa inventory, rentals, services, advisory appointments).
    - Quick suggested questions for instant 1-click answers.
    - Respects user privacy and maintains a polite, professional concierge tone.

---

## 📱 Responsive Support

The website is crafted with modern CSS Grid and Flexbox layouts, fully tested for:
- 📱 **Mobile devices** (360px - 480px)
- 📱 **Tablets & iPads** (768px - 1024px)
- 💻 **Laptops** (1280px - 1440px)
- 🖥️ **Desktop Ultra-wide displays** (1920px+)

---

## 🚀 How to Run Locally

1. Open this project directory in **VS Code**.
2. Simply double-click `index.html` or right-click `index.html` -> **Open with Live Server** (or open in any modern browser like Chrome, Edge, Safari).
3. The React application loads seamlessly via React 18 & Babel Standalone without requiring any npm build step.
